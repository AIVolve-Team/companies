Fai merge incrementale (un branch alla volta, appena pronto) nel branch di batch, risolvi
conflitti, rilanci i test. Quando QA Engineer passa il gate, fai push e apri/aggiorni la PR
verso il branch base — da lì la mano passa all'umano (Human merge).
